## Troubleshooting

### "User not found" or "Invalid credentials"

Contact your developer to:
1. Verify the user exists in Supabase Dashboard
2. Generate a new password reset link

### Password reset link expired

Password reset links expire after 1 hour. Request a new one from your developer.

### Can't access admin features

Make sure:
1. You're logged in with the correct email
2. Your role is set to "admin" in the database
3. Contact developer to verify admin role assignment
